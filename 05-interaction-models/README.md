# Mô hình tương tác ELAMS

Lưu system context, use case diagram và sequence diagram.

- System context thể hiện ranh giới ELAMS, bên tương tác và hệ thống liên quan đã được xác nhận.
- Use case diagram thể hiện actor và mục tiêu sử dụng trong phạm vi.
- Sequence diagram làm rõ thứ tự tương tác của các luồng cần phân tích, gồm kết quả thành công và lỗi liên quan.

Bắt đầu từ tương tác ở mức nghiệp vụ hoặc hệ thống. Thành phần kỹ thuật cụ thể được bổ sung sau khi đối chiếu với đội phát triển. Mỗi sơ đồ liên kết tới use case hoặc yêu cầu tương ứng.
