# Thiết kế UI và UX ELAMS

Lưu user flow, cấu trúc thông tin, danh sách màn hình, wireframe, đặc tả giao diện, phản hồi và liên kết thiết kế Figma.

Trình tự dự kiến: làm rõ tác vụ người dùng → user flow → wireframe → thiết kế UI trong Figma → prototype → rà soát với người dùng và cập nhật.

Khi tạo thiết kế Figma, ghi liên kết file và các page hoặc frame liên quan. Mỗi màn hình có mã `SCR`, liên kết tới yêu cầu và mô tả dữ liệu, thao tác, validation, quyền và các trạng thái cần thiết. Lưu bản xuất khi cần review hoặc bàn giao; xác định phiên bản để đối chiếu với thiết kế hiện hành.

Hiện tại chưa tạo file Figma hoặc thiết kế màn hình.
